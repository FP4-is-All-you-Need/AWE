# xy の候補と既存の形の照合

xy の候補 7 形を、v51 の目録と、追加前の公開版 `cd85700a1ef2372b40543c5bbc229990558e2d19` に照らした記録です。同じ形かどうかは、値の集合を区別し、リムや面の並べ替え、符号、可逆な重みの変換、A と B の交換などを正規化して比べました。公開版に無いことを、数学的に新しいことの根拠にはしていません。

法 96・積 3 回の候補は v51 の `c09945` と同じ形です。重みの列が繰り返されており、等しい列をまとめると A、B とも重みは 1 と 23 になります。実質は 1 変数の 2 リムの形です。

残る 6 形のうち、5 形は v51 の既存行と正規化後の表現が一致しました。法 256 の候補だけが v51 に一致する行を持ちませんでした。7 形とも、上記の追加前の公開版には一致する形がありませんでした。

旧目録の 454 行も対象にしましたが、記録されたリムの数が異なるため、今回の比較で同じ正規化表現にはなりませんでした。この限られた旧目録との照合も、一般的な新規性を示すものではありません。
